# OpenCode plugin

This directory is reserved for the integration defined in
[design section 13](../docs/design.md#13-opencode-integration-phase-3-surface-2-phase-5). The Python core and standalone CLI are
separate from this TypeScript front-end; the package layout is defined in design section 15.

Plugin work is tracked in [phase 3 of the development plan](../docs/development-plan.md#phase-3-opencode-plugin-milestone-m5).
Consult the plan's [task status](../docs/development-plan.md#task-status) before assuming any
plugin tool or command is available. Use the root [development instructions](../README.md#development)
for core checks; this directory has no Node package or install command.
